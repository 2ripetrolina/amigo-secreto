# Amigo Secreto 2026 🎁

Lista de desejos do amigo secreto: cada pessoa sugere o que gostaria de ganhar (nome do presente, link e foto).

- Página estática publicada pelo GitHub Pages (`index.html`).
- Os pedidos são gravados por um web app do Google Apps Script numa planilha Google, e as fotos ficam numa pasta do Drive.
- Os dados dos participantes não ficam neste repositório.
